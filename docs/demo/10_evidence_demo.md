# Evidence Demo

> A focused walkthrough of `ui/09_evidence_panel.md`, usable standalone for an audience
> specifically interested in the evidence/citation guarantee (REQ-FUNC-005).

## Script

1. **(Do)** Open the Evidence Panel for the primary scenario's answer.
2. **(Say)** "Every one of these claims has a real source — click any of them." **(Do)** Click
   through 2-3 citations, showing the exact source passage each time.
3. **(Say)** "If it can't find a source, it says so instead of guessing." **(Do)**, if
   feasible, ask a question the document doesn't answer, showing the agent's explicit
   decline rather than a fabricated response.
