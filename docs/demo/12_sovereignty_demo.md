# Sovereignty Demo

> A focused, standalone walkthrough of the Network Sovereignty Panel, for an audience whose
> primary concern is the "does this really stay offline" question.

## Script

1. **(Say)** "Don't take my word for it — watch this panel for the rest of the demo." **(Do)**
   Point out the panel's live status throughout every other demo beat.
2. **(Optional, strong closer)** **(Do)** Physically unplug the network cable on stage (if not
   already disconnected) and show the panel's status is unchanged — because it was already
   fully offline-capable, not merely offline by coincidence.
3. **(Say)** "And if anything ever tried to call out, it would show here, logged, not
   silently swallowed." **(Do)** Point to the blocked-attempts counter.
